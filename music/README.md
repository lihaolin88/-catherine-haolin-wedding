# Background music

Drop your chosen audio file here and name it `wedding-song.mp3`
(the page already points to `music/wedding-song.mp3`).

- Keep it under ~5MB so the site stays fast on mobile data.
- MP3 is the safest format for browser compatibility.
- Make sure you have the rights to use the track (royalty-free sites:
  Epidemic Sound, Artlist, YouTube Audio Library, Pixabay Music).
- Until a file is added, the music button will show a friendly toast
  instead of failing silently.
